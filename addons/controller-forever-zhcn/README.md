# Controller Forever 简体中文语言包

独立插件，依赖 **ControllerForever**，匹配上游 3.9.44。

在中文客户端自动使用 zhCN，也可用 /cr lang zhCN 测试。游戏内输入 /cr menu 打开设置。

如需停用：直接关闭 ControllerForever_ZH 插件或删除对应目录，原插件配置不受影响。

## 文件

- ControllerForever_ZH.toc — 描述依赖和语言包版本
- ControllerForever_zhCN.lua — 原生 ControllerForever.L.register("zhCN", ...) 字符串映射

多数文字基于初步机器翻译进行了有针对性的游戏术语修订；依然需要手工逐页复核。
