# Controller Forever 简体中文语言包

此目录存放独立插件 ControllerForever_ZH：原版 Controller Forever 3.9.44 的非官方简体中文界面翻译。

本版 v0.3.0-beta 为参考语言键提供 2,289 条 zhCN 映射，但仍有 1,230 条为尚未逐条语言校对的早期机器译文，请不要将其称为完整人工精校版。

将 ControllerForever_ZH 文件夹解压到 World of Warcraft/_forever_/Interface/AddOns/ 下，与 ControllerForever 并列；完全重启游戏后使用 /cr menu。

停用该插件即可恢复英文，不影响原版手柄配置。
